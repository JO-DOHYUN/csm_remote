Classification: `HARDWARE EVIDENCE / NON-AUTHORITATIVE FOR CURRENT PRODUCT OR L2`

이 폴더의 배선, bring-up, 전압, postmortem 자료는 hardware evidence다. 현재 제품
불변식, active architecture, build route, wire 또는 HIL acceptance를 재정의하지 않는다.
현재 작업은 root `CURRENT.md`, `docs/architecture/ACTIVE_ARCHITECTURE.yaml`,
`docs/operations/DEVELOPMENT_SETUP_KO.md`와 verification policy에서 시작한다.
